# AirCursor

> 将你的安卓手机变成安卓平板的无线触控鼠标与中文键盘。  
> **全程纯蓝牙连接，无需依赖 Wi-Fi 局域网，单 APK 手机平板通用，随时随地即开即用。**

---

## ✨ 核心功能

### 🖱️ 丝滑高精度的无线鼠标

### ⌨️ 手机打字直接落字上屏

- **自由输入中文**：在手机上使用你最习惯的手机输入法（九宫格、双拼、手写或语音输入均可）；
- **组词智能防截断**：手机选完词落字后才精准发送给平板，不会将未组完的拼音误发到平板；
- **软键盘实体按键映射**：在手机输入法中按退格键（Backspace）或回车键（Enter），平板端同步执行删除和换行。

### 📱 平板端无界面输入法

- **零遮挡输入**：平板端自带极简无界面输入法，输入时光标正常显示并闪烁，但屏幕 100% 干净无遮挡；
- **直接写入**：手机输入的中文或控制命令直接无缝落字写入平板当前活动输入框。

### 🛡️ 后台常驻保活不断连

- **前台通知保活**：连接建立后自动开启前台服务，手机按返回键退至后台或锁屏时，蓝牙连接依然保持稳定，不会频繁断开；
- **断线智能重试**：如遇意外断连，系统会自动尝试重连已配对设备。

### 🎨 界面与个性化

- **白天 / 黑夜主题**：支持深色模式、浅色模式以及跟随系统自动切换；
- **参数记忆**：触控板灵敏度、滚轮灵敏度、键盘模式等设置自动保存。

## 🚀 快速入门

### 第一步：获取与安装

本项目为**单 APK 双端合一**设计，手机直接安装一个安装包即可：

- 编译生成或下载 `app-debug.apk`（或 `AirCursor-v1.0-release.apk`）；
- 在**手机****上安装该应用。

### 第二步：系统蓝牙配对

1. 打开手机和平板的系统【设置】->【蓝牙】；
2. 搜索并**完成手机与平板之间的系统级蓝牙配对**。

### 第三步：连接与使用

1. 手机打开 AirCursor，授予蓝牙权限；
2. 在顶部下拉框中选中你的平板设备，点击**【连接平板】**；
3. 连接成功后，即可在手机触控板上滑动控制平板上的鼠标光标。

## 💡 平板工作模式说明

AirCursor 支持两种不同使用习惯的模式：

| 模式        | 模式一：极简直接上屏模式（推荐）                    | 模式二：厂商原生输入法模式（如 vivo 悬浮条） |
|:--------- |:----------------------------------- |:------------------------- |
| **特点**    | **屏幕完全无遮挡**，手机打字落字直接上屏              | 习惯使用平板原厂输入法候选栏与快捷条        |
| **平板端设置** | 在平板【语言与输入法】中将默认输入法切换为 **AirCursor** | 保持平板系统默认输入法不变             |
| **手机端设置** | 保持默认的【纯鼠标模式】（最稳定）                   | 在设置中勾选开启【实验性：键盘+鼠标复合模式】   |

## ❓ 常见问题 (FAQ)

#### Q1：滑动鼠标时，平板鼠标只会上下移动或界面疯狂乱窜？

- **原因**：平板系统底层缓存了旧设备的蓝牙描述符，导致报文解析错位。
- **解决办法**：
  1. 手机端确保处于默认的【纯鼠标模式】；
  2. 进入平板系统【蓝牙设置】，找到手机名称，点击**【取消配对 / 忽略设备】**；
  3. 重新搜索手机并配对连接即可完全恢复正常。

#### Q2：手机切到后台或息屏后断开了连接？

- **解决办法**：退出应用时请**直接按手机返回键**（应用会退至后台并通过前台服务通知保活），请勿在多任务卡片中强行上滑划掉应用。
